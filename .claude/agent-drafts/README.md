# Livrables intermédiaires des agents

Ce dossier reçoit les livrables texte des sous-agents UX/UI, Design, CR et SEO (volet mots-clés) avant intégration par l'agent Dev — voir `CLAUDE.md` à la racine du projet pour l'architecture complète.

Convention de nom : `<agent>-<slug>-<date>.md` (ex. `redaction-blog-tms-teletravail-2026-09-22.md`).

Ce dossier peut être nettoyé périodiquement une fois un chantier publié — les fichiers ici ne sont que des brouillons de travail, pas la source de vérité (qui est le site en ligne).
